# Changelog

## 0.4.0
- Added Knowledge Engine foundation domain model in Prisma schema (sources, collections, documents, chunks, citations, jobs).
- Added secure Knowledge Engine API routes for collections, documents, upload, document inspector, retry, archive, and lexical search.
- Added ingestion pipeline with file validation, storage abstraction, processor registry, normalization, chunking, citation generation, and job transitions.
- Added document processors for txt, markdown, csv, pdf, docx, pptx, xlsx, and image metadata.
- Replaced dashboard placeholder with functional Knowledge Hub UI for upload, search, listing, and inspector actions.
- Added parser dependencies required for document ingestion and extraction.

## 0.3.0
- Added Brand Brain page and multi-brand database actions
- Added active route navigation
- Added Supabase brand schema
- Added project documentation
- Added campaign brand selection and context injection
